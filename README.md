# Qihang Studio

> **Data, image, and the stories between them.**

Qihang Studio is my personal website and creative workspace for **data, visual practice, research, and experimentation**.

The site is designed as a place where statistical thinking and visual work can exist within the same system — not as separate portfolios, but as different ways of understanding and communicating information.

## Current Sections

- **Solutions** — data analysis, statistical reasoning, research, and computational work
- **Gallery** — visual art, design, image-making, and creative experiments
- **About** — background, experience, interests, CV, and contact
- **Language** — multilingual support, designed to scale beyond English and Chinese

## Design Direction

The visual system is built around:

- editorial typography
- generous whitespace
- restrained neutral colors
- a shared spectrum of champagne, rose, lavender, and periwinkle
- lightweight geometric elements inspired by data visualization
- minimal motion and interface decoration

The goal is to keep the site calm, precise, and visual — somewhere between a personal portfolio, a research studio, and an editorial publication.

## Tech

The current prototype is built with:
